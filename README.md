# ReadEase Library

A digital library management system with Java backend.

## Run Locally
```
javac LibraryServer.java
java LibraryServer
```
Then open http://localhost:8080

## Deploy to Railway
1. Push this repo to GitHub
2. Go to railway.app → New Project → Deploy from GitHub
3. Select this repo → Railway auto-detects the Dockerfile
4. Done! Your live URL appears in the Railway dashboard
